# Postmortems

A running log of real bugs hit while building real things — not staged, not textbook. Every entry happened during actual work: a Bash tool pushed to production, or a multi-stage security-ops agent pipeline built stage by stage.

See [BUG_LOG.md](./BUG_LOG.md) for the full log — each entry follows the same shape: what happened, what it actually was underneath, how it got caught, how it got fixed, and what it teaches that generalizes past that one bug.

This grows as new bugs get caught. Nothing here is retroactively cleaned up to look better than it was — the value is in the accuracy.
